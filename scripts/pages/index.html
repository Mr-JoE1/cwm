cwm — Claude Workspace Manager

Accounts, workspace and devices for Claude Code in one tool. Install per user — no sudo, no admin. The installer verifies the release's SHA-256 checksums, starts the dashboard agent at login and opens it.

Linux / macOS

curl -fsSL https://mr-joe1.github.io/cwm/install.sh | sh

Windows (PowerShell)

irm https://mr-joe1.github.io/cwm/install.ps1 | iex
