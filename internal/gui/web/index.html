Initialize the workspace

Creates the cwm home and config.toml; an existing ~/.claude is adopted in place. Safe to run again; existing data is kept.

Add a Claude account

Pick a short name for this login, for example work. A terminal window opens for the Claude login; this page notices when it is done.

Pair another device (optional)

Syncs the workspace with another device over Syncthing, peer to peer. Run the same pairing on the other device with this device's ID.

    ~/cwm/handoff

    Work you left on another machine that is not pushed yet: local clones with uncommitted changes (same data as cwm wip dirty).

    ~/cwm/health

    What is wrong, why it matters and the fix (same checks as cwm doctor). Stuck? Report a bug copies a redacted report and opens the form.

    ~/cwm/accounts

    Accounts are Claude logins only (same data as cwm account list): every account shares one workspace. The default is what plain claude, cwm open and Resume use; any other runs beside it with cwm run --account <name>.

    Add account

    A short name for one Claude login, for example work. A terminal window opens for the login; this page follows it.

    ~/cwm/settings

    Changes save at once to config.toml in the cwm home and apply on this machine; the switches that do more first show what they will change.

    The same from a terminal

    Every switch is also a command: cwm config list, cwm config set <key> <value>, cwm mode set.
