~/cwm/handoff

Work you left on another machine that is not pushed yet. Open it here to continue. These local clones have uncommitted changes (same data as cwm wip dirty).

~/cwm/health

report a bug

What is wrong, why it matters and the command that fixes it (same checks as cwm doctor). Stuck? Copy debug logs puts a redacted report on the clipboard for a bug report.

~/cwm/accounts

The Claude logins cwm launches with (same data as cwm account list). Each account keeps its own credentials; the default one is used by cwm open and Resume. Logging in happens in a terminal window — this page follows it.

Add account

A short name for one Claude login, for example work or personal. A terminal window opens running cwm account login <name>.

~/cwm/stats

Activity derived from the session transcripts on this machine (same data as cwm stats). Computed locally — never sent anywhere.
